# Broken Growth Ministries Website

Official public website source for Broken Growth Ministries in Pensacola, Florida.

Governance rules:
- Public claims must trace to verified or approved organizational facts.
- Do not claim 501(c)(3) recognition or tax-deductibility unless authoritative status supports it.
- Do not publish participant stories, testimonials, partner endorsements, outcome statistics, analytics IDs, API keys or credentials without verification and approval.
- External sends, donation-account changes and consequential production changes remain human-approved.
